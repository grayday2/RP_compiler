# Проверка пробного комплекта

## Пройдена реальная Windows-проверка

GitHub Actions, Windows Server 2022, Windows PowerShell 5.1:
https://github.com/grayday2/RP_compiler/actions/runs/35004511737

Проверенный исходный commit: `e080a5eb044c5ad279a24d3c3c0d2018d8b5179f`.

Успешно выполнены:
- офлайн-тесты установщика (SHA-256, отказ от перезаписи, ZIP traversal,
  неполный архив, повторная установка, вложенные .gitkeep);
- загрузка всех шести компонентов, проверка зафиксированных SHA-256,
  распаковка и запуск локальных CMake/GCC/G++/objcopy/Make/Python;
- повторный first_setup.ps1 -Offline -ValidateOnly;
- полная сборка main.cpp локальными инструментами и создание firmware.uf2;
- 11 Python-тестов на установленном портативном Python;
- путь проекта содержит пробел: `D:\RP2040 Test`.

После первого запуска CI исправлена обработка пустых вложенных папок-заготовок
cmake/bin и toolchain/bin. Это исправление покрыто отдельным тестом.

CI также настроен распаковывать именно `packages/RP2040_Portable.zip`, проверяя
его SHA-256 перед тестами. Последний результат виден в разделе Actions ветки.
Внутри архива находится исходный код и загрузчик, не готовые EXE или UF2.

## Ограничения

- На физической RP2040-плате прошивка не проверена.
- Windows 10 пользователя отличается от Windows Server 2022 runner: при ошибке
  нужны setup.log/build.log. Протестирован Windows PowerShell 5.1.
- Старое окружение не было побайтно воспроизведено: Make и упаковка GCC выбраны
  заново, TinyUSB закреплён на найденном commit-кандидате.
- main.cpp и файлы библиотеки ru_keys логически не менялись.
- Реальная ёмкость Flash и назначение GP11 на платах с AliExpress не установлены.

## Источники контрольных сумм

SDK/TinyUSB ZIP и Make EXE хешированы локально из фиксированных Git-источников.
CMake SHA-256 сверён с PogPackages; Python — с CPython release tracker и
StabilityMatrix; xPack — с npm-манифестом 13.3.1-1.1.1. Во время успешной
Windows-установки скачанные файлы прошли проверку всех этих хешей.

## Следующий шаг: уборка и оформление

Диагностика перенесена в debug/, логи — в debug/logs/. Исходник установщика
библиотек перенесён в scripts/ без изменения кода. Добавлен вопрос очистки
после успешной установки, автоматические тесты Enter/y и защиты компонентов.
CI проверяет также сборку после удаления кэша. Изменений main.cpp, библиотек,
CMake или списка версий компонентов в этом шаге нет.
