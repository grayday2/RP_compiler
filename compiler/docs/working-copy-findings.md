## Boot stage 2

- PICO_DEFAULT_BOOT_STAGE2 = compile_time_choice.
- В ASM_DEFINES цели bs2_default нет CHOSEN_GENERIC_03H; он есть только у blink_zero.
- Подключено определение waveshare_rp2040_zero.h с CHOOSE_W25Q080=1.
- Проверенная логика boot_stage2/config.h выбирает boot2_w25q080 при этом макросе.
- Вывод по конфигурации: выбран W25Q080, не generic_03h.
- Файл depend.make в отчёте содержит compile_time_choice.S и config.h, но не
  имя конкретного boot2_*.S. Дизассемблирование/сравнение байтов не выполнялось.
- Не заменяем неэффективное определение CHOSEN на реально действующий выбор
  generic под видом косметической правки: это изменило бы загрузчик.
- PICO_FLASH_SIZE_BYTES=4194304 передаётся и boot2, и приложению. Это настройка,
  а не результат измерения физической памяти платы.
- bs2_default.bin имеет 240 байт до дополнения и контрольной суммы; это не
  означает повреждение. Дополнение до формата boot2 делает следующий шаг SDK.

## Окружение и остающиеся неизвестные

Ранее установленными командами --version подтверждены CMake 3.30.5,
Arm GNU Toolchain 13.3.Rel1 / GCC 13.3.1, GNU Make 4.4.1, Python 3.10.11 x64,
SDK объявляет 2.3.0, TinyUSB — 0.21.0.

- В python/ присутствуют python310.dll, python3.dll, vcruntime140.dll,
  vcruntime140_1.dll и другие DLL. Папку переносим целиком.
- В проверенных cmake/bin и toolchain/bin DLL сканером не перечислены.
  Нельзя утверждать ни необходимость DLL именно там, ни полную статичность
  инструментов: таблицы импортов не проверялись.
- Make EXE не содержит полезных полей Company/Product/FileVersion; найденные
  README относятся к toolchain в целом и сами по себе не устанавливают источник Make.
- У TinyUSB нет .git. Нормализованные хеши двух заголовков отличаются от
  проверенного ранее релиза 0.21.0. Рабочий снимок сохраняем целиком.
- В include-путях сохранённой сборки присутствуют libraries/include и
  libraries/src, кроме ru_keys и ssd1306. Содержимое этих каталогов данным
  аудитом не установлено; не считаем их автоматически мусором.
- Хеши pico_sdk_import.cmake, tusb_config.h и uf2conv.py рабочей папки записаны
  в отчёте; их полная идентичность текущим файлам репозитория не установлена.
- Flash capacity и назначение GP11 требуют аппаратных сведений.

## Следующий этап без смены архитектуры

1. Сохранить у пользователя эталонные UF2 и полную рабочую папку.
2. Согласовать источник ru_keys.h: библиотечная копия уже подтверждена,
   избыточная корневая копия удалена после аудита по разрешению пользователя.
3. Правки скрипта сборки проверять отдельно от прошивки и внешних компонентов.
4. Не переносить установщик, не менять SDK/TinyUSB/boot2 одновременно.
5. После каждой отдельной правки: тесты, Windows-сборка и нужная проверка платы;
   при регрессии откатить последнее изменение, не накапливать обходные исправления.
