# Внутренние скрипты и вспомогательный исходник

Эта папка нужна обычным кнопкам из корня проекта:

- `build_firmware.py` — проверка файлов, запуск CMake/Make, создание UF2.
- `console_output.py` — оформление вывода и чистый файловый лог без ANSI-кодов.
- `setup_helpers.ps1` — проверка хешей, распаковка, установка и безопасная очистка кэша.
- `package_portable.py` — создание того же единственного ZIP в `packages/`; нужен разработчику.
- `lib_installer.cpp` — необязательный исходник установщика дополнительных библиотек.
  Он не участвует в сборке прошивки и автоматически не компилируется.

Отчёты и диагностические утилиты находятся отдельно в `debug/`.

## Если понадобится lib_installer.exe

Код установщика при переносе исходника не менялся. Он определяет папку проекта
относительно **готового EXE**, поэтому EXE по-прежнему должен находиться в корне,
рядом с `tmp/` и `libraries/`, а не в scripts/.

Пример сборки из корня с Windows-компилятором C++17 (не ARM-компилятором):

```bat
g++ -std=c++17 -O2 scripts\lib_installer.cpp -o lib_installer.exe
```

В Dev-C++ также задайте выходной EXE в корне проекта. Для библиотек из текущего
комплекта эта утилита не нужна; их можно добавлять в libraries/ вручную.
