# Внутренности компилятора RP2040

Эта папка содержит портативный сборочный тулчейн, библиотеки и скрипты
для компиляции прошивки RP2040 (Raspberry Pi Pico / Waveshare RP2040-Zero).

Пользователю не требуется работать в этой папке напрямую:
* Запуск первичной установки: **`first_setup.cmd`** (в корне проекта)
* Настройка макросов и сборка `main.cpp`: **`START.bat`** (в корне проекта)
* Компиляция готовой прошивки: **`compile.bat`** (в корне проекта)
* Исходник прошивки: **`main.cpp`** (в корне проекта)
* Готовая прошивка: **`output/firmware.uf2`** (в корне проекта)

---

## Структура папки compiler/

* `CMakeLists.txt` — конфигурация сборки CMake для RP2040
* `pico_sdk_import.cmake` — загрузчик Raspberry Pi Pico SDK
* `tusb_config.h` — параметры TinyUSB HID стека
* `dependencies.lock.json` — фиксированные хэши и ссылки на бинарные зависимости
* `uf2conv.py` — конвертер ELF/BIN в формат UF2
* `libraries/` — исходные библиотеки:
  * `ru_keys/ru_keys.h` — макросы клавиш для русской и английской раскладок
  * `ssd1306/` — драйвер дисплея I2C OLED SSD1306 и шрифты
  * `secrets/` — хранилище секретов
* `scripts/` — служебные скрипты сборки (`build_firmware.py`, `package_portable.py` и др.)
* `debug/` — логи установки и сборки (`setup.log`, `build.log`)
* `docs/` — подробная внутренняя документация
* `tests/` — модульные тесты инвариантов сборки
* `packages/` — архив портативного комплекта
