# Диагностика — не нужна для обычной сборки

Здесь собраны вспомогательные проверки и создаваемые логи. Основные кнопки
`first_setup.cmd` и `compile.bat` остаются в корне. Ничего из этой папки не
попадает в прошивку.

| Путь | Зачем нужен |
|---|---|
| `logs/build.log` | Полный вывод последней сборки, включая команды. UTF-8, без цветовых кодов |
| `logs/setup.log` | Полный вывод последней установки/проверки окружения |
| `env_report.bat` | Запускает небольшой отчёт через локальный `python/python.exe` |
| `env_report.py` | Python-реализация отчёта о версиях и хешах инструментов |
| `env_report.ps1` | Альтернативная PowerShell-реализация того же отчёта |
| `audit_working_copy.ps1` | Подробная проверка структуры, макросов и параметров прошлой сборки |
| `reports/` | Отчёты обеих утилит; старые отчёты сохраняются под резервными именами |
| `setup.lock` | Блокировка одновременного запуска установщика; не программа и не Git-файл |

`logs/`, `reports/` и `setup.lock` создаются по необходимости, не включаются
в Git и ZIP. Логи/отчёты можно удалять, когда соответствующие программы закрыты.
Корневые логи от старой версии автоматически не удаляются и не переносятся.

## Как пользоваться

Обычно ничего запускать не нужно. При проблеме со сборкой достаточно прислать
`debug/logs/build.log`, при проблеме установки — `debug/logs/setup.log`.
Перед отправкой просмотрите лог: в нём могут быть пути на вашем компьютере.

Для краткого отчёта дважды щёлкните `debug/env_report.bat`. Результат:
`debug/reports/compiler_structure_report.txt`.

Для подробного аудита в PowerShell:

```powershell
& '.\debug\audit_working_copy.ps1' -Root 'C:\RP2040_Test'
```

Скрипты не читают содержимое main.cpp и не ищут пароли. При запрете PowerShell
согласуйте запуск с политикой вашего компьютера или используйте Python-вариант.

## Что здесь не хранится

- `scripts/` содержит необходимую механику сборки и установки — её нельзя
  удалить, считая только отладочной папкой.
- `tests/` — автоматические тесты разработки; `docs/` — подробная документация.
- `.setup-cache/` в корне — скачанные архивы, `.setup-work/` — временная распаковка.
  После успешной установки на вопрос очистки нажмите **y и Enter**, чтобы
  удалить именно эти две папки. Просто **Enter** сохраняет их и завершает запуск.
- Установленные `cmake/`, `toolchain/`, `python/`, `pico-sdk/`, исходники,
  `output/firmware.uf2` и их контрольные метки при очистке не затрагиваются.
