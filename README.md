# RP_compiler

Билдер («компилятор для компилятора») прошивки сервисной клавиатуры на
RP2040 (Raspberry Pi Pico + SSD1306 + энкодер, TinyUSB HID-клавиатура).

Репозиторий **не содержит** настоящий `main.cpp` устройства: в нём
служебные пароли и логины, поэтому он собирается билдером из фрагментов
и конфигов прямо на вашей машине.

## Быстрый старт

1. `START.bat` (Windows, русская кодовая страница; билдер сам делает `chcp 866`).
2. В меню: добавьте пароли (пункт 1) и фразы (пункт 2), при необходимости
   проверьте модули макросов (3) и клавиатуры (4).
3. Пункт **5 (BUILD)** — собирает готовый `builder/out/main.cpp`.
4. Скопируйте `builder/out/main.cpp` в ваш проект прошивки и соберите
   Pico SDK как обычно (в проекте нужны `ssd1306_i2c.h` и `ru_keys.h`).

## Что где лежит

| Путь | Назначение |
|---|---|
| `START.bat` | запуск билдера |
| `builder/BUILDER.bat` | главное меню |
| `builder/modules/*.bat` | модули: auth / support / macros / keyboard / build |
| `builder/lib/*.bat` | библиотеки: токенизация текста, проверки |
| `builder/src/*.inc` | C-фрагменты, из которых склеивается `main.cpp` |
| `builder/data/*.txt` | рабочие конфиги (пароли/фразы) — **исключены из git** |
| `builder/data/*.example` | примеры конфигов |
| `builder/out/main.cpp` | результат сборки (исключён из git) |
| `builder/README.md` | подробная документация (форматы, токены, правка) |

## Безопасность

В git **не коммитятся**: `builder/data/auth.txt`, `builder/data/support.txt`,
`builder/src/20_macros.inc`, всё из `builder/out/` и `builder/tmp/`
(см. `.gitignore`). В репозитории лежат только шаблоны-примеры без
служебных данных.
