# RP_compiler

Билдер («компилятор для компилятора») прошивки сервисной клавиатуры на
RP2040 (Raspberry Pi Pico + SSD1306 + энкодер, TinyUSB HID-клавиатура).

Репозиторий **не содержит** настоящий `main.cpp` устройства: в нём
служебные пароли и логины, поэтому он собирается билдером из фрагментов
и конфигов прямо на вашей машине.

---

## Быстрый старт (Windows)

1. **`FIRST_SETUP.bat`** (запустить один раз):
   * Создаст рабочие конфиги из примеров (`data/auth.txt`, `data/support.txt`,
     `src/20_macros.inc`).
   * Если в системе не установлен Python — скрипт сам скачает официальный
     портативный (embeddable) Python с `python.org` в папку `runtime/python`.
     **В систему ничего не устанавливается, права админа не нужны.**
2. **`START.bat`** — запускает билдер.
3. В меню: добавьте пароли (пункт 1) и фразы (пункт 2), при необходимости
   отредактируйте макросы (3) и клавиатуру (4).
4. Пункт **5 (BUILD)** — собирает готовый `builder/out/main.cpp`.
5. Скопируйте `builder/out/main.cpp` в ваш проект прошивки и соберите
   через Pico SDK как обычно (в проекте нужны `ssd1306_i2c.h` и `ru_keys.h`).

---

## Запуск на Linux / macOS

```bash
python3 builder/builder.py
```
Никаких внешних библиотек (pip) не требуется — используется только
встроенная стандартная библиотека Python.

---

## Что где лежит

| Путь | Назначение |
|---|---|
| `FIRST_SETUP.bat` | первый запуск: разворачивание конфигов + портативный Python |
| `START.bat` | запуск билдера в один клик |
| `builder/builder.py` | движок билдера (меню, токенизация, сборка) |
| `builder/src/*.inc` | C-фрагменты, из которых склеивается `main.cpp` |
| `builder/src/20_macros.inc.example` | шаблон макросов группы CMD (в git) |
| `builder/src/20_macros.inc` | реальные макросы со служебными данными (**в .gitignore**) |
| `builder/data/*.example` | примеры конфигов в UTF-8 (в git) |
| `builder/data/*.txt` | рабочие конфиги паролей и фраз (**в .gitignore**) |
| `builder/out/main.cpp` | готовый файл прошивки (создаётся при сборке) |
| `builder/README.md` | подробное руководство (форматы, токены, меню) |
| `main.cpp` | заглушка в корне репозитория |

---

## Безопасность

В git **никогда не коммитятся**:
* `builder/data/auth.txt`
* `builder/data/support.txt`
* `builder/src/20_macros.inc`
* `builder/out/*`
* `runtime/`

В репозитории лежат только безопасные шаблоны-примеры. Ваши реальные
пароли и логины хранятся только на локальной машине.
