# RP_compiler: Портативный компилятор + Билдер прошивки RP2040

Полный автономный комплект для сборки и кастомизации прошивки сервисной
клавиатуры на **RP2040** (Waveshare RP2040-Zero / Raspberry Pi Pico + OLED SSD1306
+ поворотный энкодер, эмуляция USB HID-клавиатуры через TinyUSB).

Комплект объединяет:
1. **Основной портативный компилятор** (CMake + GCC ARM toolchain + Make + Pico SDK + TinyUSB).
2. **Интерактивный билдер прошивки** (`builder/`): безопасный ввод паролей, русских фраз поддержки, сборка чистого C-кода `main.cpp`.
3. **Единое портативное окружение Python**: один и тот же Python используется установщиком, билдером и компилятором. Никаких сторонних установок в систему не требуется!

## Быстрый старт (все шаги из одного архива)

### 1. Скачайте репозиторий
Скачайте ветку архивом через кнопку **Code → Download ZIP** на GitHub
(или используйте прямой архив [RP2040_Portable.zip](packages/RP2040_Portable.zip)).
Распакуйте в отдельную папку (например, `C:\RP2040_Project`).

### 2. Запустите `first_setup.cmd` (или `FIRST_SETUP.bat`)
* Скачивает и разворачивает фиксированные версии инструментов:
  * CMake 3.30.5
  * xPack GCC ARM toolchain 13.3.1
  * GNU Make 4.4.1
  * Портативный Python (в папку `python\`)
  * Raspberry Pi Pico SDK 2.3.0 + TinyUSB 0.21.0
* Инициализирует конфиги билдера из безопасных шаблонов `*.example`.
* **В систему ничего не ставится**, права администратора и правка реестра не нужны.
* Интернет требуется **только один раз** при первом сетапе.

### 3. Запустите `START.bat` (билдер)
Билдер запускается через портативный Python и открывает меню:
* **[1] AUTH** — добавление паролей (ввод скрыт, посимвольная отправка `A_SEND` без `Enter`);
* **[2] SUPPORT** — фразы технической поддержки на русском языке (авто-токенизация `RU_*`);
* **[3] MACROS** — сервисные сценарии группы CMD (`src\20_macros.inc`);
* **[4] KEYBOARD** — страницы экранной клавиатуры устройства;
* **[5] BUILD** — генерирует готовый к компиляции `main.cpp` прямо в корень проекта;
* **[6] COMPILE** — запускает компиляцию прошивки прямо из меню билдера.

### 4. Скомпилируйте прошивку
Либо выберите пункт **[6] COMPILE** в билдере, либо запустите **`compile.bat`**.
Компилятор собирает прошивку полностью офлайн и сохраняет её в:
```
output\firmware.uf2
```
Лог сборки сохраняется в `debug\logs\build.log`.

### 5. Прошейте RP2040
1. Зажмите кнопку **BOOTSEL** на плате RP2040.
2. Подключите плату к компьютеру по USB и отпустите BOOTSEL (появится съемный диск `RPI-RP2`).
3. Скопируйте файл `output\firmware.uf2` на диск `RPI-RP2`. Плата автоматически перезагрузится с новой прошивкой!

```

├── START.bat                   # запуск билдера (использует python\python.exe)

├── START_HERE.txt              # краткая инструкция для быстрого старта
│
├── main.cpp                    # заглушка в git -> перезаписывается билдером

├── pico_sdk_import.cmake       # инициализация Pico SDK
├── tusb_config.h               # конфигурация TinyUSB

│

│   ├── builder.py              # движок билдера (меню, токенизация, сборка)

│   │   └── support.txt         # ВАШИ реальные фразы (в .gitignore)

│   │   ├── 00_header.inc       # инклюды, пины, структуры

│   │   ├── 20_macros.inc       # ВАШИ реальные макросы (в .gitignore)

│   ├── ru_keys/ru_keys.h       # макросы русских/латинских клавиш для HID
│   ├── ssd1306/                # драйвер и шрифты экрана OLED SSD1306
│   └── secrets/secret_store.h  # хранилище секретов
│
├── scripts/                    # служебные скрипты
│   ├── build_firmware.py       # драйвер сборки через CMake + Make
│   ├── console_output.py       # форматированный вывод
│   ├── setup_helpers.ps1       # хелперы скачивания и распаковки
│   └── package_portable.py     # сборка дистрибутивного zip-архива
│
├── debug/                      # отчёты и логи (setup.log, build.log)
├── docs/                       # внутренняя документация архитектуры
```

## Безопасность

Чувствительные данные (служебные пароли, логины, приватные макросы)
**никогда не попадают в git**.

В репозитории хранятся только безопасные шаблоны `*.example` и заглушка `main.cpp`.
Ваши реальные файлы:
* `builder/data/auth.txt`
* `builder/data/support.txt`
* `builder/src/20_macros.inc`
* сгенерированные файлы `builder/out/main.cpp` и `output/firmware.uf2`
добавлены в `.gitignore` и остаются только на вашей локальной машине.
