# Билдер прошивки сервисной клавиатуры (RP2040)

Билдер собирает готовый к компиляции `main.cpp` для устройства
«сервисная клавиатура» (RP2040 + OLED SSD1306 + поворотный энкодер,
эмуляция USB-клавиатуры через TinyUSB).

Логика работы:

* **данные** (пароли, фразы поддержки) хранятся в обычных текстовых
  конфигах `data/*.txt` в кодировке **UTF-8** (читаются и правятся
  любым блокнотом, а также через меню билдера);
* **код** разбит на независимые C-фрагменты `src/*.inc`;
* пункт меню **BUILD** (или пункт 5) собирает фрагменты и сгенерированные
  секции в единый файл `out/main.cpp`, который готов к компиляции
  через Pico SDK.

---

## Быстрый старт и запуск

Билдер написан на Python (только стандартная библиотека, без сторонних
зависимостей). Подходит любая версия Python 3.8+.

### Вариант 1 (автономный / переносной, для Windows):
1. Запустите **`FIRST_SETUP.bat`**:
   * Создаст рабочие файлы `data/auth.txt`, `data/support.txt` и
     `src/20_macros.inc` из примеров (`*.example`), если их ещё нет.
   * Если на компьютере не установлен Python — скрипт сам скачает
     официальный портативный (embeddable) Python с `python.org` в
     папку `runtime/python/`. **В систему ничего не ставится**, права
     администратора не нужны.
2. Запустите **`START.bat`** — он откроет меню билдера.

### Вариант 2 (напрямую через Python на любой ОС):
```bash
python builder/builder.py
# или:
cd builder && python builder.py
```

## Меню билдера

```
==================================================
   RP2040 SERVICE KEYBOARD :: БИЛДЕР main.cpp
==================================================

  [1] AUTH     -- пароли: добавить / просмотр / удалить
  [2] SUPPORT  -- фразы:  добавить / просмотр / удалить
  [3] MACROS   -- модуль макросов CMD (просмотр/правка)
  [4] KEYBOARD -- модуль клавиатуры (просмотр)
  [5] BUILD    -- собрать main.cpp
  [0] ВЫХОД
```

### [1] AUTH — пароли (просто посылка клавиш, A_SEND)
* Ввод пароля: **символы скрыты** при вводе (в терминале ничего не
  отображается ради безопасности).
* Допустимы любые латинские буквы, цифры и знаки препинания:
  `! @ # $ % ^ & * ( ) - _ = + [ ] { } \ | ; : ' " , . / ? ~ пробел`.
* Пароль конвертируется в токены клавиш (`LAT_*`, `DIG_*`, `SYM_*`).
* Действие при выборе в меню устройства — **`A_SEND`**: прошивка
  просто печатает пароль посимвольно (без Enter, без лишних окон
  или сценариев).

### [2] SUPPORT — фразы поддержки
* Ввод фразы: обычный русский текст с клавиатуры.
* Допустимы все русские буквы (заглавные и строчные), цифры, пробел
  и знаки препинания: `, . - : ! ?`.
* Автоматически конвертируется в токены русской раскладки (`RU_*`,
  `RU_SPACE`, `RU_COMMA`, `RU_DOT` и т.д.).
* В прошивке печатается через действие **`A_TEXT`**: сначала нажимается
  `Ctrl+A` (выделить поле ввода), затем печатается фраза.

### [3] MACROS — модуль макросов CMD (`src/20_macros.inc`)
* Содержит сервисные команды и многошаговые сценарии
  (`TECHLOCAL`, `SUDO PASSWD`, `CD AUTORUN`, `NET DISKS`, `VIDREG`,
  `SERIALNOM`, `SUDO REBOOT`, `ENERGY SAVE`, `YANDEX`, `DION`, `ZSOPRIV`).
* Хранится в готовом виде как C-фрагмент.
* Количество пунктов меню в группе вычисляется автоматически через
  `sizeof`, поэтому при добавлении макроса не нужно вручную менять
  счётчики.

### [4] KEYBOARD — модуль экранной клавиатуры устройства
* `src/40_keyboard.inc` — раскладки страниц (LOWER, DIGITS, SYMBOLS,
  COMBOS, NANO, FUNC1, FUNC2) и их клавиши.
* `src/60_keyboard_ui.inc` — отрисовка страниц на экране SSD1306,
  навигация энкодером, посылка HID-отчётов.

### [5] BUILD — сборка готового `out/main.cpp`
Собирает все фрагменты и сгенерированные таблицы в единый файл
`builder/out/main.cpp`. Файл сразу готов к компиляции в Pico SDK.

## Форматы конфигурационных файлов

Все конфиги лежат в папке `builder/data/` в кодировке **UTF-8**.
Строки, начинающиеся с `;`, считаются комментариями и игнорируются.

### `auth.txt` (пароли)
```
ИМЯ|ТОКЕНЫ
```
Пример:
```
NOLOGIN_PW|LAT_M,LAT_U,LAT_P,LAT_E,LAT_T,LAT_D,LAT_O,LAT_G,DIG_2,DIG_2,SYM_EQUAL,SYM_EQUAL
```
* **ИМЯ** — отображается в OLED-меню группы AUTH (до 15 символов,
  латиница, цифры, пробел, `-`, `_`).
* **ТОКЕНЫ** — разделённая запятыми цепочка токенов клавиш.

### `support.txt` (фразы)
```
ИМЯ|ТОКЕНЫ|ТЕКСТ
```
Пример:
```
KONSULTACIA|RU_T_CAP,RU_R,RU_E,...,RU_DOT|Требуется консультация, серийный недоступен...
```
* **ИМЯ** — пункт в OLED-меню группы SUPPORT (латиница).
* **ТОКЕНЫ** — токены клавиш русской раскладки.
* **ТЕКСТ** — человекочитаемый русский текст (используется только для
  просмотра в меню, при сборке в C-код не попадает).

## Справочник токенов клавиш

Токены определены в заголовке `ru_keys.h` вашего проекта RP2040:

* **Латиница**: `LAT_A` .. `LAT_Z` (строчные), `LAT_A_CAP` .. `LAT_Z_CAP` (заглавные).
* **Русские буквы**: `RU_A` .. `RU_YA` (строчные), `RU_A_CAP` .. `RU_YA_CAP` (заглавные),
  буква «ё» — `RU_YO` / `RU_YO_CAP`.
* **Цифры**: `DIG_0` .. `DIG_9`.
* **Знаки препинания в русском тексте**:
  `RU_SPACE` (пробел), `RU_COMMA` (запятая), `RU_DOT` (точка).
* **Специальные символы (ASCII)**:
  `SYM_SPACE`, `SYM_EXCL` (`!`), `SYM_AT` (`@`), `SYM_HASH` (`#`),
  `SYM_DOLLAR` (`$`), `SYM_PERCENT` (`%`), `SYM_CARET` (`^`), `SYM_AMP` (`&`),
  `SYM_STAR` (`*`), `SYM_LPAREN` (`(`), `SYM_RPAREN` (`)`), `SYM_MINUS` (`-`),
  `SYM_UNDER` (`_`), `SYM_EQUAL` (`=`), `SYM_PLUS` (`+`),
  `SYM_LBRACK` (`[`), `SYM_RBRACK` (`]`), `SYM_LBRACE` (`{`), `SYM_RBRACE` (`}`),
  `SYM_BSLASH` (`\`), `SYM_PIPE` (`|`), `SYM_SEMI` (`;`), `SYM_COLON` (`:`),
  `SYM_SQUOTE` (`'`), `SYM_DQUOTE` (`"`), `SYM_COMMA` (`,`), `SYM_LT` (`<`),
  `SYM_DOT` (`.`), `SYM_GT` (`>`), `SYM_SLASH` (`/`), `SYM_QMARK` (`?`),
  `SYM_TILDE` (`~`).

## Порядок склейки финального `main.cpp`

При выборе пункта **BUILD** билдер объединяет части в таком порядке:

1. `src/00_header.inc` — общие заголовочные файлы, дефайны пинов,
   enum `Action` (с действием `A_SEND`), структуры `Item` и `Group`.
2. **Сгенерированная секция SUPPORT** — массивы `sup_<имя>[]` и
   таблица `support_items[]`.
3. `src/20_macros.inc` — массивы и таблица `cmd_items[]` (группа CMD).
4. **Сгенерированная секция AUTH** — массивы `auth_<имя>[]` и
   таблица `auth_items[]` (все с действием `A_SEND`).
5. `src/40_keyboard.inc` — массивы страниц экранной клавиатуры и
   структура `keyboard_group`.
6. **Сгенерированная таблица groups[]** — связывает все 4 группы,
   размеры вычисляются через `sizeof`.
7. `src/50_engine.inc` — навигация по меню энкодером, отправка HID-пакетов,
   специальные сценарии макросов, дескрипторы TinyUSB.
8. `src/60_keyboard_ui.inc` — логика работы экранной клавиатуры.
9. `src/70_main.inc` — инициализация железа (I2C, GPIO, TinyUSB) и
   главный цикл `while (true)`.

## Безопасность

В git **не попадают** (прописаны в `.gitignore`):
* `builder/data/auth.txt` — ваши настоящие пароли;
* `builder/data/support.txt` — ваши рабочие фразы;
* `builder/src/20_macros.inc` — служебные учётные данные из макросов CMD;
* `builder/out/*` — собранные файлы;
* `runtime/` — локальный портативный Python.

В репозитории хранятся только безопасные шаблоны с суффиксом `.example`.
При первом запуске скрипт `FIRST_SETUP.bat` (или сам `builder.py`) автоматически
создаёт рабочие копии из этих шаблонов.
