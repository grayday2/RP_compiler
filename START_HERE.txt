RP2040 PORTABLE + BUILDER — ПОЛНЫЙ КОМПЛЕКТ

Единый архив: портативный компилятор Pico SDK + модульный билдер прошивки.
Используется единый портативный Python, не требует прав администратора.

БЫСТРЫЙ СТАРТ:

1. Распакуйте архив в НОВУЮ папку, например C:\RP2040_Project.
2. Запустите first_setup.cmd (или FIRST_SETUP.bat).
   * Скачает и развернёт портативный тулчейн (CMake, GCC ARM, Make, Python, Pico SDK, TinyUSB).
   * Создаст стартовые конфиги билдера (пароли, фразы, макросы).
   * Интернет нужен только для первичной установки.
3. Запустите START.bat — откроется меню билдера:
   * [1] AUTH     -- настройте пароли (ввод скрыт, посылка клавишами A_SEND)
   * [2] SUPPORT  -- настройте русские фразы поддержки
   * [3] MACROS   -- проверьте сервисные макросы CMD (src\20_macros.inc)
   * [4] KEYBOARD -- экранная клавиатура устройства
   * [5] BUILD    -- соберёт готовый main.cpp прямо в корень проекта
   * [6] COMPILE  -- скомпилирует готовую прошивку output\firmware.uf2
4. Либо запустите compile.bat отдельно.
5. Готовая прошивка: output\firmware.uf2.
   Переведите RP2040 в режим загрузчика (удерживая кнопку BOOTSEL при подключении)
   и скопируйте firmware.uf2 на появившийся диск RPI-RP2.

Ошибки сборки: логи сохраняются в debug\logs\setup.log и debug\logs\build.log.
Подробности: README.md и builder\README.md.
